# .github

本仓库用于存放 **王毅乐课题组（Yile Wang Lab）** 的组织级配置。

- [`profile/README.md`](profile/README.md) —— 组织介绍，展示在组织主页 <https://github.com/YileWang-Lab> 的顶部

> 说明：GitHub 会固定从组织的**公开 `.github` 仓库**的 `profile/` 目录读取 `README.md` 作为组织主页介绍。
> 若还想给组织成员配置一份仅内部可见的介绍，需要另建**私有**的 `.github-private` 仓库，同样是 `profile/README.md`。
