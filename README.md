# .github

本仓库用于存放 **王毅乐课题组（Yile Wang Lab）** 的组织级配置。

- [`profile/README.md`](profile/README.md) —— **公开版**组织介绍，展示在组织主页 <https://github.com/YileWang-Lab>

> 说明：GitHub 会固定从组织的**公开 `.github` 仓库**的 `profile/` 目录读取 `README.md` 作为组织主页介绍。
> **成员可见的内部版**介绍位于**私有**仓库 [`YileWang-Lab/.github-private`](https://github.com/YileWang-Lab/.github-private) 的 `profile/README.md`；
> 组织成员登录后访问组织主页默认看到内部版，并可手动切换到公开视图。
