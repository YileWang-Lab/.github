## 欢迎 👋

欢迎来到 **王毅乐课题组** 的 GitHub 组织主页。

我们是一个将**前沿机器学习方法**与**计量经济学**、**金融学**相结合的研究单位。我们关心真实世界的经济与金融问题，也关心解决这些问题所需的方法论创新 —— 在严谨的计量框架下，让新的学习方法真正服务于经济学与金融学研究。

**我们接受所有热爱科研的同学。**

## 研究方向

- **机器学习 × 计量经济学** —— 因果推断、因果机器学习、高维与稀疏建模、非参数方法
- **机器学习 × 金融学** —— 资产定价、实证金融、风险与波动率建模、金融文本与另类数据
- **前沿方法** —— 深度学习、大语言模型、强化学习在经济学与金融学中的应用
